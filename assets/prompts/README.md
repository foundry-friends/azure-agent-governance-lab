チャット送信回数は MCP の初期化・再試行・複数操作を含むツール要求数と一致しません。quota 試験の対象・集計キー・上限・期間・試験経路が未確定なら Pending にします。実施順と復旧は[第8章](../../docs/08-governance-tests.md)に従います。
