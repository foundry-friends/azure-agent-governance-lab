# Run 0. 準備（机上）

このセクションを使う Run: Run 0。先に要るセクション: S0。

> **Note** 骨組み・Azure 未実行です。

## 0.1. 目的

Run 1 の前に権限・社内 IP・予算・固定版とパラメータを机上で確定します。

## 0.2. 前提

[概要](../../README.md) と [設計判断](../00_design.md) を読みます。Azure の構築は行いません。

## 0.3. 構築

### 前日までの確認

1. S1 で RG 作成・RBAC 割当・Policy・Defender・予算の実効権限を確認します。
2. S3 で社内公開 IP を確定します。
3. S2 で既存の Entra 条件付きアクセスと CAE を変更せず確認します。
4. モデル版・Japan East のクォータを確認します。
5. 見積り v3 で予算・期間・CSPM・公開規程の承認状況を記録します。
6. [固定コミット](../../infra/PINNED_COMMIT.md) を確認します。
7. [41 の param](../../infra/params/41_parameters.md) と自前ラッパを照合します。
8. BYO・IP 制限・ローカル認証と S5/S6/S7 の未解決点をレビューします。
9. S1 の予算通知の値を確定します。

| 作業 | 時間 |
|---|---:|
| 会社ルール・権限・社内 IP・CA | 2h |
| テンプレ固定・パラメータ確定レビュー | 2h |
| 組み替えたリポのレビュー | 2h |
| 合計 | 6h |

> **Note** 承認待ちと並行して 1〜2h 単位に分割できます。

## 0.4. 確認

机上作業だけで C01〜C10 を合格にしません。予算通知の実確認は Run 1 の C10 に引き継ぎます。

## 0.5. うまくいかない場合

> **Note** 要確認: GA 適合性、権限、モデル提供、BYO 到達、後追い更新、S6 接続が未確定なら Run 1 の実行を保留します。

## 0.6. 削除

Azure を作成しないため削除はありません。既存環境の費用ゼロを確認した意味ではありません。

## 0.7. 費用

机上作業の Azure 費用は $0 です。既存契約や環境費は別です。

## 0.8. 本番との差

本番との差は [付録 B](../92-appendix-production-diff.md) に残します。
