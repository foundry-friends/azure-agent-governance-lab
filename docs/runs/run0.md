# 旧 Run 0 文書について（参考）

このページは旧リンクから来た人への案内です。通常の実行手順は [README の第0〜10章](../../README.md#ハンズオンここから順番に進める) に統一しました。

旧方式では準備・最小構成・ゲートウェイを複数回に分け、それぞれ構築と削除を行っていました。現在は一つの環境で最後まで進め、削除は第10章で行います。

再現確認は任意の二周目です。初回に作ったものは第10章で削除し、別の実施回として同じ順序をたどります。途中章へ戻ることを通常手順にはしません。

`infra/params/run1.example.json`・`run2.example.json` と `scripts/deploy.sh --run` は旧 IaC モード名を維持しています。新しい本文の途中で実行するものではありません。固定停止点を解除していません。
