# 非公開の証跡テンプレート

このファイル自体は空のひな形です。**記入したコピー・画面・実測値は、部門が承認した非公開ストレージ、または Git 管理対象外の `evidence/` にだけ保存します。** このファイルへ実データを上書きしません。共有ストレージの場所・アクセス権・保存期間はチームで確定します。

非公開でも、APIキー・トークン・パスワード・秘密鍵は保存しません。画面の不要な実名・ID・入力本文はマスクします。Issueには公開用の要約と匿名の証跡番号だけを転記し、共有URLや実測値を貼りません。

## 記載例（すべて架空・実機検証結果ではありません）

- 証跡番号：EV-001
- 実施日・手順の版：<実施日>／<コミットSHA>
- 工程・試験行：第7章 7.3 工程7／C08 App Service → Foundry 到達
- 条件：社内ブラウザ、利用者としてサインイン済み、Standard
- 操作：合成入力 TEST-001 を送信
- 期待結果：対象エージェントから応答を得る
- 実際の結果：画面に403を伴うエラーが表示された。拒否した層は未特定
- 判定：Pending
- 根拠：403だけでは本人認可とネットワークのどちらで拒否されたか判別できない
- 画面：EV-001-screen-redacted.png（架空のファイル名）
- 復旧：設定変更なし。後続の依存試験は停止
- 引き継ぎ：統合先・VNet規則・本人権限を担当者が照合。期限は<再確認日>
- 公開用の要約：アプリ送信時にエラー。原因未特定のためC08の当該行はPending。証跡EV-001を非公開保管

許可された操作が期待に反して拒否され、条件も特定できた場合はFailです。上の例は拒否層と条件の照合が未完了のためPendingとしています。期待した拒否が根拠付きで確認できた場合はPassになり得ます。個々の行の結果を、C番号全体の合格へ読み替えません。
